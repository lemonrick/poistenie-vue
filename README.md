# ✈️ Travel Insurance Calculator (Quasar + Vue)

[Live Demo](https://lemonrick.github.io/poistenie-vue/)

## ✅ Requirements
- Node.js `22+`
- Yarn `1.22+`

## 📦 Install
```bash
yarn install
```

## 🛠️ Development
```bash
yarn dev
```

## 🚀 Production Build
```bash
yarn build
```

## 🧪 Tests
```bash
yarn test
```
